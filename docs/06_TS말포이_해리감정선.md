## 1. 한 줄 정의 (팬덤 표현 그대로 모으면)
- 루리웹: "**해리에게 집착하는 귀족 아가씨**", "**자존심 강한 허접 츤데레 악역 영애**"

- 샘웨 영상(42만): "처음엔 되게 강한 척하다가 **금방 무너지는 허접**이라 무해하다. 남자 허접은 찌질이가 되는데 여자 허접은 귀여워진다"
- AO3: "**그녀가 먼저 빠졌다, 조용하고 아프게**", "증오가 둘 다 인정 못 할 무언가로 변함", 갈등의 원천은 "**그녀의 자존심과 그의 둔감함**"

→ 핵심 공식: **먼저 빠진 쪽은 그녀, 인정 못 하는 것도 그녀, 그래서 늘 지는 것도 그녀.**

## 2. 감정의 뿌리 — 원작에서 이미 있던 것 (팬들이 "원작 그대로인데 성립한다"고 하는 이유)
1. **먼저 호의를 보인 건 말포이다.** 원작 옷가게 첫 만남에서 드레이코는 해리에게 먼저 말을 걸고 수다를 떤다(부모님 얘기, 빗자루, 퀴디치, 기숙사). 팬 영상 「말포이는 첫눈에 반했고, 해리는 질렸다」(5.6만)가 바로 이 장면.
2. **처음 거절당한 사람.** 추종자들 사이에서 자란 아이가 처음으로 손을 거절당함 → 그 뒤 7년의 시비는 "관심을 끌 다른 방법을 모르는 것"으로 읽힌다.
3. **비정상적인 5년 집착.** 기숙사컵을 뺏기고, 아버지가 이사직에서 쫓겨나고, 히포그리프에 다치고, 족제비가 돼도 계속 해리에게 덤빈다. 남자면 찌질함, 여자면 애증.
4. **진심 섞인 걱정.** "위즐리나 해그리드 같은 애들이랑 어울리면 물든다"는 원작 대사가, TS로 보면 해리를 진짜 걱정한 말로 읽힌다(샘웨 영상).
5. **원작 대사가 질투 대사로 바뀐다.** 원작에서 해리에게 던진 비꼼("여자친구라도 생겼냐" 류)이 성별만 바꾸면 질투로 들린다(샘웨 영상에서 가장 크게 반응한 부분).
6. **위기 때 떠올리는 사람.** 6권, 가족 몰살 위협 속에서 혼자 울 때 — 늘 이겨 내던 그 안경 쓴 녀석(김준표 영상). 패트로누스의 "가장 행복한 기억"이 해리라는 만화(sigmman 3부작)도 같은 축.

## 4. 팬덤이 그리는 감정 곡선
```
① 호의(먼저 말 걸고 들뜸) → ② 거절(인생 첫 거절, 울먹) → ③ 집착성 시비(관심 끌기)
→ ④ 입덕부정("~거든!", 핑계, 몰래 흔적) → ⑤ 질투로 들킴(주변이 다 앎)
→ ⑥ 위기에 의지(약한 모습, 해리 생각) → ⑦ 고백/인정(패트로누스, 화해) → ⑧ 연인이어도 츤
```
- 사람들이 가장 많이 보는 구간은 **④·⑤** (핑계·질투·들킴 = 조회수 상위 대부분).
- AO3 장편은 ⑥·⑦을 길게(slow burn, mutual pining).

## 5. 해리(=사용자)의 역할
- 팬 작품의 해리는 **능글맞고, 받아치고, 둔감하다.** 댓글: "해리 겁나 나쁜 남자네, 저 조련력은".
- 그녀를 이기는 건 해리뿐 → **사용자가 받아치면 이기게 설계**해야 재미가 산다.
- 둔감함이 갈등의 원천(AO3) → 사용자가 눈치 없이 굴어도 그녀는 직접 말 못 하고 돌려 말함.

## 6. 피해야 할 것 (팬덤 반응 근거)
- **캐릭터성이 죽는 TS**: 그냥 예쁜 순한 여자애로 만들면 "말포이 매력이 없어진다"는 비판(루리웹). 오만·도발이 기본값이어야 함.
- **무조건 강한 일진녀**: 팬들이 좋아하는 건 강한 척하다 무너지는 허접. 끝까지 이기는 말포이는 매력 반감.
- **얀데레/어두운 집착**: 71만 영상처럼 수요는 있지만 배포 앱 기본값으로는 위험. 집착은 "일정 캐묻기·삐치기"까지.
- **성적 코드**(우유 밈, 크기 논쟁, '입 벌려' 등): 조회수는 높지만 우리 앱·영상에선 제외.

## 7. 페르소나·데이터에 반영할 것 (제안)
1. **시그니처 말버릇**: 들키면 "~거든!"으로 변명. 단 남발 금지(대화 5~6번에 한 번 꼴).
2. **관계 단계 재설계** (감정 곡선 ③~⑧에 맞춤): `앙숙(집착성 시비)` → `라이벌(입덕부정)` → `들킴(질투가 새어 나옴)` → `휴전(약한 모습을 보임)` → `특별함(인정하지만 여전히 츤)`
3. **대화 데이터 분포 조정**: 핑계 만들기 15%, 질투 12%, 들킴·변명 12%, 허접 붕괴(사용자에게 짐) 12%, 일상 시비 15%, 원작 기억 12%, 상처받음·위로 8%, 선물·칭찬 반응 5%, 자연스러운 회피 5%, 현실 생활 받아치기 4%.
4. **앱 기능 연결**: 부엉이 우편 = "핑계 편지"(목도리 돌려줘, 숙제 물어볼 거 있어). 장면 모드 = 원작 장면에서 ④·⑤ 순간을 체험.
