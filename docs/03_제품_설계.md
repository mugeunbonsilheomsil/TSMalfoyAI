# 제품 설계 — AI TS 말포이 (배포판)

## 1. 배포 구성
```
[설치 파일 .exe (Electron)]  ← 우리가 배포하는 건 이것 + LoRA뿐
   ├─ 설치 매니저 (첫 실행)
   │    GPU/VRAM/디스크 검사 → 맞는 llama.cpp 빌드(CUDA/Vulkan/CPU) 다운로드
   │    → 베이스 GGUF 다운로드(Hugging Face, 이어받기 + SHA256 검증)
   │    → 페르소나 LoRA(GGUF) 다운로드 (우리 GitHub Release)
   ├─ 로컬 엔진: llama-server (127.0.0.1 전용, 외부 접속 없음)
   └─ 앱 UI
```
- 모델 파일은 우리가 재배포하지 않고 원 저장소에서 직접 받음 → 용량·라이선스 부담 최소.
- 인터넷은 설치 때만. 대화는 100% 오프라인.

## 2. 베이스 모델 (2026-10-14 확정: Gemma 4 E4B 원본, QAT)
- 학습: `google/gemma-4-E4B-it-qat-q4_0-unquantized` (Apache-2.0). 상세는 [04_E4B_학습_조사.md](04_E4B_학습_조사.md)
- 배포 GGUF (같은 가중치라 LoRA 하나로 둘 다 맞음):
  - 기본 `google/gemma-4-E4B-it-qat-q4_0-gguf` → `gemma-4-E4B_q4_0-it.gguf` 5.15 GB
  - 저사양 `unsloth/gemma-4-E4B-it-qat-GGUF` → `UD-Q2_K_XL` 3.22 GB
- 설치 매니저가 VRAM 보고 자동 선택 (6 GB↑ → Q4_0, 그 아래/CPU → Q2_K_XL)
- 무검열 모델(HauhauCS 12B)은 쓰지 않음: 원본 모델이 부적절한 요청을 대화 흐름 속에서 자연스럽게 피하는 성향을 살림.

## 3. "그냥 채팅"이 아닌 핵심 기능 3개
1. **기억하는 대화 + 관계 단계**
   앙숙(집착성 시비) → 라이벌(입덕부정) → 들킴(질투) → 휴전(약한 모습) → 특별함(인정하지만 츤) — [06 감정선](06_TS말포이_해리감정선.md). 게이지 숫자는 안 보여 주고 **호칭·말투가 바뀌는 걸로만** 체감. 대화에서 사용자가 말한 사실(시험, 야근, 좋아하는 것)을 기억해 며칠 뒤 꺼냄.
2. **장면 모드**
   원작 명장면 10개에 포터로 들어가 그녀와 직접 겪는 짧은 시나리오(해당 학년 그대로)(선택지 + 자유 입력). 관계 단계에 따라 같은 장면도 반응이 다름 → 반복 플레이 동기.
3. **부엉이 우편 (먼저 말 거는 AI)**
   트레이 상주(선택). 하루 1~2통 짧은 편지 알림. 편지는 늘 **핑계 편지**(목도리 돌려줘, 숙제 물어볼 거 있어 — 06 문서 A): 새벽까지 PC 켜 두면 잔소리, 며칠 안 오면 삐친 편지, 기억해 둔 일정 챙기기. 이게 영상·SNS에서 "얘가 먼저 연락함" 바이럴 포인트.

## 4. UI (기업형, 필요한 것만)
- 좌측 얇은 내비 4개: **대화 / 장면 / 우편함 / 설정**
- 대화: 상단 바(이름 + 관계 단계 텍스트 한 줄), 메시지 영역, 입력창. 아바타는 표정 시트에서 감정에 맞게 1장.
- 설정: 모델(자동/수동), 부엉이 우편 on/off·시간대, 기억 초기화, 데이터 폴더 열기, 라이선스·고지.
- 색: 거의 흑백 + 포인트 1색(짙은 초록). 장식·마법 효과 없음.
- 첫 실행 설치 화면: 단계 표시(검사 → 엔진 → 모델 → 페르소나 → 완료), 진행률·속도·남은 시간, 실패 시 재시도.

## 5. 안전장치 (배포 필수)
- 원본 모델의 회피 성향이 LoRA 학습 후에도 유지되는지 **학습 전/후 같은 위험 질문 30개로 비교 검사** (파인튜닝은 회피 성향을 약하게 만들 수 있음). 데이터에 "말포이다운 회피" 5% 포함.
- 비공식 팬 프로젝트 고지, 해리 포터 공식 로고·폰트 미사용, 무료 배포.
- 텔레메트리 없음.
