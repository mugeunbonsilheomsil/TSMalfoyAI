## 앱 (`app/`)
Electron 44 + llama.cpp b11612. `npm start` 로 실행 (개발: `npm run dev` → 127.0.0.1:7870 원격 조작/스크린샷).
- `src/hardware.mjs` GPU/VRAM/RAM 검사 → 엔진·모델 추천 · `src/installer.mjs` 이어받기 + SHA256 + zip 해제 · `src/manifest.json` 받을 파일 목록
- `src/engine.mjs` llama-server 127.0.0.1 전용 기동, 미사용 시 내려서 VRAM 반환, 생각 모드 끔
- `src/persona.mjs` 관계 5단계·기억·장면·부엉이 우편 · `persona/` 캐릭터·장면 데이터 (+ `malfoy-lora.gguf` 넣으면 자동 적용)
- `ui/` 디자인 시스템(다크/라이트, Pretendard·고운바탕 OFL), 프레임 없는 창

실측 (RTX 4070, LoRA 적용): CUDA+MTP 96 tok/s · CUDA 77 · Vulkan 65 · CPU 14
