# TS 말포이 페르소나 데이터

사용자=포터. 원작 사건·학년을 유지하며 성격의 결만 제공된 TS 문서의 공통 장치로 해석했다. 원작·팬 작품 대사는 인용하지 않았다.

- character_sheet.md: 외모·가족·성격·말투·취향·금기·빚.
- relationship_stages.json: 5단계, 단계당 조건 5/3과 대표 대사 5.
- scenes.json: 원작 사건 10개, 각 선택지 3개.
- dialogues.jsonl: 600개. batches/의 6개 파일은 이 본문의 순서와 동일한 100개 묶음.
- bad_examples.jsonl: 부정 예시 30개. 정답 대화 학습에 섞지 말고 평가용으로 분리한다.
- dataset_index.json: 줄 번호별 주제와 사건·학년 조건. 미래 기억 방지에 필요하다.
- validation_report.json: 실제 파싱·수량·중복·문장 수 검사 결과.
- source_manifest.json: 읽은 문서의 해시와 편집상 구분.

JSONL의 2~6턴은 사용자·assistant 메시지 2/4/6개로 표현했다. 대부분 짧은 한 쌍이며 일부는 2~3쌍의 연속 대화다. 모든 단계에 120개씩 배분했고, 주제 비율은 전체 600개에서 정확히 맞췄다. 모든 주제가 각 단계에 존재하지만 72·48·24개 항목은 5로 나누어떨어지지 않아 단계별 개수에 1개 차이가 있을 수 있다.

관계 단계는 학년과 독립적이다. 사건 회상 데이터를 학습하거나 추론에 사용할 때 인덱스 조건을 주입하지 않으면 저학년의 미래 기억을 이 파일만으로 막을 수 없다. 현재 학년·날짜·발생 사건·관계 단계는 로더가 별도로 관리해야 한다.

같은 표현 반복은 완성 문장·완성 대사가 3회 이상 등장하지 않는 기준으로 검사했다. 포터·호그와트 등의 고유명사와 일반 어미는 반복될 수 있다. 자동 검증은 형식과 정확한 반복을 확인하며, 유사한 의미의 표현까지 수학적으로 배제하지는 않는다.

전체_코드블록.md는 요청한 모든 결과물을 파일명과 코드블록으로 수록한다. 600개는 001–100부터 501–600까지 6블록이다. 대화_001–100.md 등은 해당 묶음만 따로 읽거나 복사하기 위한 문서다.
